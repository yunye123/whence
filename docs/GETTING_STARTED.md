# 开始使用来处

[English](GETTING_STARTED.en.md) · [返回介绍](../README.md)

本指南适用于 **MVP 0.1.0**。应用界面为简体中文。Windows 11 已有实际运行验证；macOS、Linux 以及全新机器上的视频下载与自动转写流程暂未验证。

## 1. 准备与启动

安装 Node.js 24 LTS，保留随附的 npm。取得源码后，在包含 `package.json`、`studio/`、`electron/` 和 `shared/` 的根目录打开终端。先检查版本：

```sh
node --version
npm --version
```

Node 的输出应为 `v24.x.x`。然后依次执行，上一条成功后再执行下一条：

```sh
npm ci
npm run build
npm start
```

`npm ci` 按锁文件安装依赖，需要网络；Electron 下载也可能受网络影响。`npm run build` 构建应用，`npm start` 打开桌面窗口。这些命令不会生成签名安装包。

需要修改源码时，在根目录运行：

```sh
npm run dev
```

运行项目测试：

```sh
npm test
```

测试中的浏览器契约检查在未设置 `FIELD_TEST_CHANNEL` 时使用 Playwright 自带的 Chromium；设置该变量后仍走指定通道。执行 `npm run build` 后，可运行 `npm run test:e2e` 完成桌面核心流程检查：它会打开独立测试窗口，在忽略的 `studio/output/` 内保存临时资料与报告，并使用本机端口 5198。

日常资料保存在 `studio/.native-profile/`，不会提交到 Git。迁移电脑或更新源码前请导出备份。首次构建后也可双击根目录的 `Start Whence.cmd` 启动。

Electron 下载失败时，网络恢复后运行 `npm run runtime:install` 重试。使用网络代理时，需让终端的 Node.js 进程也能访问 GitHub。

测试通过不代表所有视频站点、硬件环境或操作系统都已验证。

## 2. 从一块示例画布开始

首次打开时，可以选择与你当前工作相近的入口：

| 入口 | 先试这件事 |
| --- | --- |
| 我写文章 | 打开资料，查看摘录如何进入文稿，再回查出处。 |
| 我做视频 | 打开示例逐字稿，点击时间点，再查看脚本中的引用。 |
| 我做创意 | 查看图片与笔记，移动卡片，用分组整理参考。 |

示例用于演示操作，示例逐字稿不是一次真实自动转写的验收结果。准备开始自己的项目时，选择“从空白画布开始”。

## 3. 收集、摘录、写作

1. **收集资料。** 添加笔记，或通过导入、拖放添加图片、视频、TXT 和 Markdown。文字文件按正文导入，不保留 Word 等文档的排版。
2. **留下出处。** 在文字阅读面板或视频逐字稿中选择内容，使用“摘录到画布”。视频摘录保留时间，文字摘录保留原文快照与来源。
3. **写下理解。** 在摘录的“我的理解”中记录判断，再用连线、分组组织材料。原文与自己的理解可以分别保留。
4. **形成文稿。** 新建文稿，写正文、插入参考，并在需要留住一个阶段时保存版本。自动保存与主动保存版本承担不同用途。
5. **回查来源。** 从文稿中的引用或“本稿来源”回到资料；视频可定位到对应时间。使用“返回文稿”继续写作。

网页链接卡只保存链接和你粘贴的文字，不会抓取网页正文。桌面版导入公开的 X 帖子时会请求 `api.fxtwitter.com`；图片只允许来自 `pbs.twimg.com`。

原资料或逐字稿后来修改，不会自动改写已摘录的快照。来源移除后，摘录快照仍可保留，但不能再把回查当作原资料仍然可用的证明。

## 保存与导出

内容保存在本机。留意界面的保存状态：出现保存失败时，不要把当前内容当作已经备份。桌面模式与浏览器模式的工作区可能不同，也不会自动同步。

打开“导出”，按用途选择：

| 导出项 | 用途与范围 |
| --- | --- |
| 便携画布文件（`.field.json`） | 保存布局、连线、文字、版本和限制内的媒体，可重新导入继续编辑。 |
| 另存完整画布目录 | 桌面版保存独立目录副本，适合包含大视频的画布；导出时必须能读取相关素材。 |
| 文稿与参考资料（Markdown） | 导出文稿、笔记和摘录，引用转为脚注；不替代完整画布备份。 |
| 分镜脚本（PDF） | 选择文稿后输出脚本，适合阅读、打印和交付。 |
| 灵感板（PNG / PDF） | 将图片整理为可分享的视觉参考。 |

导出后确认成功提示，并打开文件检查。用于备份的画布应重新打开一次，确认文字和关键素材可读取。不要只凭生成了文件名就认定备份完整。清除应用或浏览器数据前，先确认已有可用副本。

## 可选：视频下载与本机转写

基础笔记、写作和画布整理不要求 Python。视频链接下载与自动语音识别需要额外工具，并从桌面入口使用。

| 依赖 | 用途 |
| --- | --- |
| Python 3.12 | 运行下载与转写工具。 |
| `yt-dlp` | 获取视频链接对应的媒体。 |
| `faster-whisper` | 本机语音识别。 |
| FFmpeg 与 ffprobe | 媒体处理及信息读取，两个程序都需要。 |
| 本地 Whisper 模型 | 提供转写所需的模型文件；不包含在源码仓库中。 |

Python 包必须安装在应用实际使用的 Python 环境中。当前媒体工具支持通过以下环境变量指定位置；在启动应用前设置，修改后重新启动：

| 变量 | 指向的内容 |
| --- | --- |
| `CANVAS_PYTHON` | Python 可执行文件。 |
| `CANVAS_FFMPEG` | FFmpeg 可执行文件。 |
| `CANVAS_FFPROBE` | ffprobe 可执行文件。 |
| `CANVAS_MODEL` | 兼容 `faster-whisper` 的本地模型目录。 |

未设置这些变量时，Windows 仍用 AppData 中的 Python 3.12、FFmpeg 和 ffprobe；macOS 与 Linux 默认是 `python3`、`ffmpeg`、`ffprobe`。模型目录一律是 `~/.cache/faster-whisper/large-v3`。非 Windows 因此不再被写死的 `.exe` 路径挡住；这不表示视频下载或转写已在 macOS、Linux 上验收。

这些依赖需要单独安装和配置，`npm ci` 不会安装 Python 工具或下载模型。模型大小、运行速度和可用计算设备取决于实际环境。本流程尚未在全新机器上完成端到端验证。

配置就绪后，可从“导入 → 视频链接”提交链接，再按界面提示下载并提取逐字稿。自动识别文字需要校对；也可以使用已有字幕进行整理。下载需要访问视频站点，站点登录、访问限制、过期或删除的内容均可能导致失败，不保证所有站点可用。下载失败时，先保留来源链接，再查看任务卡给出的原因。

## 可选：把英语译成中文

笔记、摘录、文稿和视频逐字稿里的英语，可以在桌面版译成简体中文。原文留在原来的位置，译文写在同一张卡片或同一句字幕上，不会另建一份存储。浏览器里打开时没有这条能力。逐字稿译好以后，可以在「原文」和「中文稿」之间切换，打开时停在中文稿。把逐字稿摘到画布时优先用中文；某一句还没有译文时仍用原文。

在侧栏底部打开「翻译密钥」，填写接口密钥后保存。密钥用系统加密保存在这台电脑的来处资料里，不会写入画布，也不会出现在导出的文件里。保存后不必重新启动。地址和模型可以留空，留空时用下面的默认值。

也可以仍在启动前设置环境变量。应用里保存过密钥时，以应用里的为准。

| 变量 | 作用 |
| --- | --- |
| `CANVAS_TRANSLATE_API_KEY` | 没在应用里保存密钥时使用。 |
| `CANVAS_TRANSLATE_BASE_URL` | 可选。默认 `https://api.deepseek.com`。也可以写成已经包含 `/chat/completions` 的完整地址，或在「翻译密钥」里填写。不要把密钥写进地址。 |
| `CANVAS_TRANSLATE_MODEL` | 可选。默认 `deepseek-v4-flash`。也可以在「翻译密钥」里填写。 |

下面只是占位，不要把真实密钥提交到仓库：

```sh
export CANVAS_TRANSLATE_API_KEY="your-key"
export CANVAS_TRANSLATE_BASE_URL="https://api.deepseek.com"
export CANVAS_TRANSLATE_MODEL="deepseek-v4-flash"
```

Windows PowerShell：

```powershell
$env:CANVAS_TRANSLATE_API_KEY="your-key"
```

英语内容旁边会出现“译成中文”。已经译出一部分时是“继续翻译”，全部译完后可以“重新翻译”。中文内容不显示这个按钮。摘录的原文快照保持英语；卡片上如果还没有单独的“我的理解”，会显示“译文”。密钥未配置或请求失败时，原文保持不变，并显示原因。

## MVP 限制

- 没有账户、云同步或多人协作。英语译成中文是可选能力，只在桌面版配置了接口密钥后才会向外请求；没有内置云端账户。自动语音识别属于可选本机处理。
- 桌面版再次启动会回到已经打开的窗口。只读只发生在同一来源的第二个页面，例如两个浏览器标签打开同一工作区：后打开的页面只读。关掉正在编辑的页面后，重新载入另一个页面再编辑。
- 每张画布最多 500 张卡片、1500 条连线；每个工作区最多 100 张画布；每篇文稿最多 100 个保存版本。
- 便携画布文件最多 96 MiB；其中单个媒体最多 64 MiB，媒体二进制合计最多 68 MiB。这些是便携文件限制，不是所有素材的统一上限。超限时使用桌面版完整目录导出。
- TXT / Markdown 导入最多 10 万字符、1 MB。分组用于整理画布，不是可嵌套的永久分组实体。
- 逐字稿支持句段文字校对，不提供字词级时间调整。自动转写的准确度需要按实际素材核对。

## 遇到问题

| 情况 | 先检查 |
| --- | --- |
| 找不到 `node` 或 `npm` | Node.js 是否安装完成；重新打开终端后再查版本。 |
| `npm ci` 失败 | 是否位于仓库根目录、Node 是否为 24，以及依赖下载是否被网络阻断。保留实际报错。 |
| `npm start` 失败 | 先确认 `npm run build` 成功，再根据终端报错定位。 |
| 画布只读 | 是否还有另一个浏览器标签打开同一工作区。桌面版再次启动会回到已有窗口。 |
| 下载或转写失败 | Python 环境、工具路径、模型是否就绪，以及任务卡中的具体错误。 |
| 译成中文失败 | 侧栏「翻译密钥」是否已保存，或启动前是否设置了环境变量。地址和模型是否正确，以及界面上给出的原因。不要把密钥发给别人。 |
| 便携导出提示超限 | 使用桌面版“另存完整画布目录”，并确认素材仍可读取。 |

反馈问题时，提供版本、系统、操作步骤、预期结果和实际报错。提交截图或日志前移除个人路径、私人内容与凭据。
